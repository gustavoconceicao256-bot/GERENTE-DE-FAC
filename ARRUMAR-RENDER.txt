CORREÇÃO DO ERRO HTTP 429 NO RENDER

Esta versão mantém o processo ativo quando o Discord responde HTTP 429 durante
 o login. As novas tentativas usam espera progressiva (30 s até 15 min), sem
reiniciar o processo nem repetir chamadas em sequência.

CONFIGURAÇÃO NO RENDER
- Tipo recomendado: Background Worker.
- Build Command: pip install -r requirements.txt
- Start Command: python bot.py
- Configure DISCORD_TOKEN no Environment do Render.
- Mantenha somente uma instância deste bot usando o token.

Se o token real já apareceu em .env.example, GitHub, ZIP público ou mensagem,
regenere-o no Discord Developer Portal imediatamente e atualize o Render.
O tratamento de 429 não remove bloqueios impostos pelo Discord; ele apenas
aguarda antes de tentar novamente.
